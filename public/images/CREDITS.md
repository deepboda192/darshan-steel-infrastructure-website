# Photography credits

Stock photographs in this folder are from [Unsplash](https://unsplash.com) or
[Pexels](https://www.pexels.com), under licences that permit free commercial use
without attribution; DSI's own photographs and catalogue artwork are marked as
such. Credits are recorded here so every file can be traced back to its source.

Every photograph is stored as WebP with smaller renditions beside it
(`name-480.webp`, `name-768.webp`, …) and an entry in `src/data/image-manifest.ts`,
all written by `node scripts/optimize-images.mjs`. To replace a photo, drop the
new JPEG or PNG in this folder under the same name and run the script.

**These are stock photographs, not DSI's own work.** Replace any file with a real
DSI photograph of the same name and the site picks it up with no code change.
